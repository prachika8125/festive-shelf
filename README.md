# The Festive Shelf

A learning space for kids. 
Festive Shelf is a digital bookshelf made for children, where they can open a storybook for each day of Tihar and Chhath, turn its pages, and learn the story behind each festival along with a mini-game.



https://festivalstories.vercel.app/

## Run locally (Windows CMD)
```
npm install
npm run dev
```
